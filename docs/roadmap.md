# 次の開発順

## 1. v0.2受入を固める

- PostgreSQL実DBでマイグレーション・全API・競合/企業分離テストを実行。
- Playwrightで生成→編集→承認→再読み込み、担当者権限、390px幅を実行。
- PC/スマホの視覚QA、キーボード・スクリーンリーダーの確認。
- Docker/Windowsを実行。文書化した手順で初回セットアップを再現。
- GitHub用リポジトリを作りCIを実行。既存NAVILOGには入れない。

## 2. ポートフォリオとしての技術的な厚み

- 代表的な質問・曖昧な質問・根拠なし・悪意のある資料を含む評価セット。
- 実装済みチャンク検索を基準に、必要なら埋め込みとハイブリッド検索を比較する。
- 資料版履歴・内部メモは実装済み。次は顧客との会話履歴・再オープン理由。
- AIの非同期ジョブ、処理停止の回復、二重実行防止、メトリクス。
- APIキーを安全に設定し、架空データで実AI接続と引用の意味的整合性を検証。
- 実行デモと設計判断・改善前後・不具合修正事例をREADMEへ追加。

## 3. NAVILOGへ戻る

この新作で検証した検索・引用・不足時の保留・評価方法を、NAVILOGの運行記録に適用する。
テナント/営業所/本人の閲覧権限を検索前に適用し、運転可否の自動決定はしない。
