# v0.2 変更点

- 資料の先頭しか引用できなかった問題を修正。段落・800文字チャンク単位で検索し、後半の該当箇所を引用。
- 資料の過去版を画面から閲覧。
- チーム内メモを履歴として保存。AI送信内容には含めない。
- 2分以上停止した生成をレビュアーが復旧。遅延応答による状態の巻き戻りを防止。
- 通信失敗時にフロントの生成キーを維持。再送による重複生成を防止。
- メモ保存時に編集中の返信文を保持。ログアウト時に画面状態を消去。
- 37テスト成功、TypeScript/Viteビルド成功、架空データ入りSQLite復元実証。

DBスキーマの変更はありません。0001は維持。v0.1のDBをそのまま使用できます。
PostgreSQL・Docker・Windows・ブラウザE2E/視覚QA・実OpenAI接続は未検証。完成判定は保留しています。GitHubでソースを公開し、CIでの追加検証を進めます。
